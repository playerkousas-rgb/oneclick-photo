⚙️ API 設定

🇭🇰 香港提示：Google AI Studio / Gemini API 對香港地區有區域限制。如果你攞唔到 Google API Key，請改用 OpenRouter(支援香港,用信用卡儲值)或任何 OpenAI 相容服務(例如阿里雲百鍊 qwen-image-edit)。
📖 去邊度攞 Key?(逐個睇)
Google Gemini
1. 去 aistudio.google.com/apikey(香港可能需要 VPN)
2. 用 Google 帳號登入 → Create API key → 複製
3. 貼上面框,模型揀 gemini-2.5-flash-image(即係 Nano Banana,人物相似度最好)

OpenRouter(香港推薦)
1. 去 openrouter.ai/keys → 用 Google/GitHub 登入
2. 儲值少少(每次生成大約 US$0.03)
3. 建立 API Key,貼上面框;模型填 google/gemini-2.5-flash-image-preview

OpenAI 相容(自訂)
填 Base URL + Key + 模型名,例如 OpenAI 的 gpt-image-1、 阿里雲百鍊 qwen-image-edit(Base URL 用服務商提供嘅 compatible-mode 網址)。
🔒 API Key 只會存喺你自己部機嘅瀏覽器(localStorage),唔會上傳去任何地方。呢個網頁係純前端,冇後台。

❓ 使用說明

1. 上載一張相 — 你嘅正面清晰相,AI 會鎖住你嘅樣貌、髮型、眼鏡、身形同衣著。
2. 揀效果 — 109 個選項(角度、鏡頭、光線、動態、無人機、構圖、特效、背景、色彩、風格),撳一下就生成, 唔需要識寫指令。每個制上面嘅圖就係效果示範。
3. 睇結果 — 撳圖片可以放大、同原圖左右對比、下載,或者「以此圖為基礎繼續改」。
4. 多選模式 — 開咗之後可以一次揀幾個效果,跟住按「生成所選」批量生成。

寫真貼士
· 上載相:最好係正面、光源均勻、解像度 1000px 以上、單人、衣著清楚。
· 生成角度太奇怪?正常,AI 會用原圖推測未見過嘅角度;可以再生成一次,或者換另一張參考相。
· 人物唔夠似?參考相太細、側面或者有遮擋就會差啲;試用正面大頭相加全身相各一張(用「＋加參考圖」)。
