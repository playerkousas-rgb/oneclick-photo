# 🟢 版本一:Gemini 免費版(用 Gmail 登入就得)

**原理**:呢個版本唔會直接呼叫 AI,而係幫你**寫好 109 條精確指令**。你喺 Gemini 度上載相,再貼上指令就出圖 —— 完全免費、唔使填任何 Key。

## 最快用法(30 秒,唔使整 Gem)

1. 下載 `photo-angle-gem.html` → 用 **Chrome** 打開。
2. 撳 **🚀 即時開始** → 開場白會自動複製,同時開啟 gemini.google.com(未登入就用你嘅 **Gmail 登入**)。
3. 喺 Gemini 對話:**貼上開場白 → 上載你嘅相**。
4. 返到網頁,喺「效果目錄」揀想要嘅效果,撳 **📋 複製指令**。
5. 返去 Gemini **貼上 → 送出** → 出圖 ✅。想第二個效果,重複 4-5 步。

## 順手用法(整一次 Gem,之後最方便)

1. 去 **gemini.google.com** → 左邊 **Explore Gems** → **New Gem**(或者直接開 `gemini.google.com/gems/create`)。
2. 名稱填:**一鍵換角度**。
3. 撳網頁嘅 **📋 複製 Gem 系統指令**(共 2,639 字,已為 Gem 欄位長度量身訂造),貼入 **Instructions** 欄。
   > 唔想複製?直接用 `GEM-系統指令.txt` 呢個檔案(開住全選複製)。
4. **Default tool 揀「Create image」** ← 好重要,揀咗佢先會直接出圖。
5. 撳 **Save**。之後每次開呢個 Gem,只要上載相 + 貼效果指令就得。

## 想分享畀朋友(好似你貼嗰個網站咁)

1. 建立好 Gem → 喺 Gem 頁面撳 **分享 / Share** → 複製連結(格式:`https://gemini.google.com/gem/...`)。
2. 貼落網頁入面嘅「分享連結」格 → **儲存連結**。
3. 之後撳 **🚀 即時開始** 就會直接開你嘅 Gem。朋友用自己嘅 Gmail 登入,一樣用同一套指令。

## ⚠️ 免費版要知道嘅事

- **每日上限**:Google 曾公佈免費帳號每日約 **20 張**圖片(2026 年 3 月),之後**唔再公佈數字**,而且會隨地區/時間調整。達到上限就等第二日重置,或升級 Google AI 方案。
- **水印**:免費版輸出會有可見水印 + Google SynthID 隱形標記;商用前請自行評估。
- **Gem 建立要用電腦網頁版**,手機建立唔到(建立好之後手機 App 用得到)。
- 貼指令係為咗令 Gemini **100% 知道你想點改**,唔會亂猜 —— 你完全唔需要自己寫指令。

# 🔵 API 自動版(photo-angle.html)詳細用法

上載 **1 張你嘅相**,然後好似你貼嘅參考圖咁,唔使打任何指令,只要**撳一下按鈕**(例如「俯瞰動作」「無人機跟拍」「黃金時刻」「移除背景」),
AI 就會用**你嘅樣貌**生成同一個效果嘅相。全部 109 個效果都已經內置好提示詞,你只需要撳掣。

## 一、點用?(3 步)


1. **下載** `photo-angle.html` → 用 **Chrome / Edge** 打開(雙擊就得,唔需要安裝任何嘢,亦唔需要上網伺服器)。
   ⚠️ 喺對話預覽視窗入面只可以「睇介面」:預覽係沙盒 iframe,冇網絡、冇 localStorage,所以**生成唔到圖**、Key 亦唔會記住。真正要用請下載檔案。
2. 撳右上角 **⚙️** → 揀服務 → 貼上 **API Key** → 儲存。(只做一次,之後會自動記住。)
3. 撳 **① 上載你嘅相** → 揀 **③ 揀一個效果** → 完成 ✅ 圖會出現在「生成結果」。

> 💡 想試效果但未想畀錢?未填 Key 都可以撳掣,會顯示**效果示範圖**,等你睇清楚每個效果係咩樣。
>
> 📦 檔案只有 0.53 MB(109 張示範圖已內嵌),可以離線用、可以電郵傳、可以隨時改名做 index.html 上網。

## ⭐ 最推薦做法:「分享對話」(米克師同款,已實測)

> **重要發現(2026-10-08 實測)**:米克師嗰條連結係 `gemini.google.com/**share**/...`,
> 即係**「分享對話」,唔係 Gem**。原因:
> - Gem 分享對外常常開唔到(而且**用 Gem 開嘅對話唔可以畀其他人繼續**)
> - 分享「普通對話」→ 朋友撳「**繼續**」→ 對話連同全部指示 fork 落佢自己帳戶 → 即刻可用

### 做法(3 分鐘)
1. `gemini.google.com` → **新對話**(普通對話,唔好揀 Gem)
2. 打開 `分享對話-貼上內容.txt` → 複製「第一條訊息」→ 貼上 → 送出
3. 複製「第二條訊息」→ 送出(Gemini 會答「明白,請上載你嘅相片」)
4. 對話右上角 **⋮ / 分享** → **建立公開連結** → 複製(`share.gemini.google/...`)
5. 將連結貼落網站分享欄,或交畀我幫你更新網站按鈕

### 朋友嘅用法
撳連結 → 撳「**繼續**」→ 對話落咗佢自己帳戶 → 上載相 → 打編號(例如 `30` 黃金時刻)→ 出圖

⚠️ 如果第 4 步冇「建立公開連結」選項 → Workspace 帳戶可能被管理員關閉咗公開對話連結 → 用**個人 Gmail** 做一次

### 三種分享方式對照
| 方式 | 匿名開得到 | 朋友可用 | 推薦 |
|---|---|---|---|
| Gem 分享 | ⚠️ 常失敗 | ❌ 唔可以繼續 | 後備 |
| **分享對話** | ✅ | ✅ 撳「繼續」即用 | ⭐ 首選 |
| 網站 + 擴充功能 | — | 要裝擴充功能 | 進階 |

## 🆕 分享版功能(舊方法:網站 + Gem 連結)

米克師嗰個網站其實係:**一個普通網頁 + 一條 Gemini Gem 分享連結**。你而家一樣做到:

1. 喺 Gemini 建立「一鍵換角度」Gem(用 `GEM-系統指令.txt`)。
2. 喺 Gem 頁面撳 **分享 / Share** → 揀「**任何人擁有連結**」→ 複製連結。
   · 個人 Gmail: 一般會有「任何人擁有連結 / 公開」選項
   · Workspace 帳戶: 要 admin 開(見下面「Workspace 注意」),而且可能只可以分享畀同機構
3. 打開 `photo-angle-gem.html` → 貼上嗰條連結 → 撳 **📤 產生「分享版」檔案**。
4. 會下載 `photo-angle-share.html` —— **Gem 連結已寫死喺檔案內**。
5. 將呢個檔案改名 `index.html`,上傳去任何網頁空間(Cloudflare Pages / Netlify 免費)就完成。
   朋友打開 → 撳「🚀 即時開始」→ 直接開你嘅 Gem → 上載相 → 打個編號 → 出圖。

> 亦支援 **`?gem=` 網址參數**:例如 `你的網址/index.html?gem=https://share.gemini.google/xxxx`,
> 咁就唔使重新產生檔案都可以指定 Gem。

### ⚠️ 分享連結格式(最常出錯嘅位)

| 你見到嘅連結 | 係咩 | 可唔可以分享 |
|---|---|---|
| `gemini.google.com/u/2/gem/9bee3ef6e86d` | 你自己嘅 Gem 網址(`/u/2` = 你登入嘅第 2 個 Google 帳戶) | ❌ 唔可以,朋友開會冇權限 |
| `gemini.google.com/gem/9bee3ef6e86d?usp=sharing` | ✅ 正確分享連結 | ✅ 可以 |
| `share.gemini.google/xxxx` | ✅ Google 短連結 | ✅ 可以 |

**攞正確連結嘅位置**:`gemini.google.com` → 左邊欄 **Gems / Explore Gems**(Gem **清單頁**)→ 你個 Gem 隔籬嘅 **分享** 圖示
→ 彈出同 Google Drive 一樣嘅視窗 → 「一般存取權」改做 **任何人擁有連結** → **複製連結**。

> 💡 **分享掣喺清單頁,唔係喺對話入面** —— 好多人入咗去 Gem 對話,見到網址係 `/u/2/gem/…` 就以為係分享連結。

**點驗證**:複製連結 → 開無痕視窗(Ctrl+Shift+N)→ 貼上 → 開到 = ✅ 成功。

> 🔧 網站已內置自動修正:貼上 `/u/2/gem/…` 呢種網址,會自動變成
> `https://gemini.google.com/gem/9bee3ef6e86d?usp=sharing` 並提示你。

### Workspace 帳戶注意(重要)
| 項目 | 實情 |
|---|---|
| 可唔可以整 Gem | ✅ 可以(Workspace 支援) |
| 分享畀「同機構同事」 | ✅ 預設開,Gem 頁面揀「你的機構」 |
| 分享畀「任何有連結嘅人」(公開) | ⚠️ 由管理員控制。Gems 分享係行 **Google Drive 分享設定**;若 Drive 禁止對外分享,Gem 就分享唔到出去,而且 work/school 帳戶嘅分享選單**可能冇「任何人擁有連結」呢個選項** |
| 想穩陣分享畀全世界 | 👉 用**個人 Gmail 帳戶**建立 Gem 最簡單;或者叫 admin 去 Admin console → Generative AI → Gemini app → Gems / Drive 分享設定開啟 |
| 30 秒自我檢測 | 整好 Gem → 撳「分享」→ 睇下有冇「**任何人擁有連結**」。有 = 做得;冇 = 被管理員限制 → 改用個人 Gmail |

## 六、常見問題

**Q:人物唔夠似?**
A:① 換一張更正面的參考相;② 加多一張全身照做參考;③ 避免用極端角度(魚眼、墊天)於樣貌要求高嘅用途;④ 任何 AI 生成都會有偏差,重要用途請多生成幾次揀最好嘅。

**Q:顯示「連線失敗」?**
A:① 用 Chrome / Edge(唔好用預覽 iframe,因為沙盒會封鎖網絡);② 確認 Key 冇抄漏;③ Google 的話可能係香港區域限制 → 改用 OpenRouter。

**Q:想確認 Key 有冇問題?**
A:撳 ⚙️ → **🧪 測試連線**。呢個測試只會讀取免費端點(唔會產生費用):
· Gemini → 列出你嘅模型
· OpenRouter → 顯示已用金額 / 上限
· OpenAI 相容 → 確認 Base URL 通唔通
生成失敗時亦會自動重試 3 次(遇到 429 / 5xx 會自動等一等再試)。

**Q:會唔會上傳我張相去其他地方?**
A:相片同 Key 都只喺你部機嘅瀏覽器處理;只會直接送去你自己設定嘅 AI 服務(Google / OpenRouter / OpenAI)。呢個網頁冇後台、冇伺服器、冇追蹤,亦冇第三方廣告。

**Q:想改做自己嘅網站?**
A:直接將 `photo-angle.html` 改名做 `index.html`,上傳去 **Cloudflare Pages**(免費)就得,香港同全世界都開到。⚠️ 網站形式會將 Key 存喺訪客自己嘅瀏覽器,唔好將你嘅 Key 寫入檔案。

**Q:想加自己嘅效果/改中文名?**
A:改 `photoangle/tools/presets_data.py`(加一行:指令、中文名、提示詞),再執行 `python3 tools/build.py` 就會重新砌出 HTML。

## 七、檔案結構(方便日後修改)

```
photo-angle.html           ← API 自動版(單一 HTML,離線可用)
photo-angle-gem.html       ← Gemini 免費版(用 Gmail 登入,推薦)
photoangle/
  ├─ assets/thumbs_hi/     ← 示範圖原檔(150px 版本用於網頁,呢個係備份)
  ├─ tools/build_gem.py    ← 打包 Gemini 免費版 + 兩個 txt 指令檔
  ├─ app/gem.template.html ← Gemini 免費版網頁原始碼
  ├─ tools/presets_data.py ← 109 個效果的資料庫(中文名 + 提示詞)
  ├─ tools/build.py        ← 重新打包:python3 tools/build.py
  ├─ tools/slice_tiles.py  ← 由你 15 張截圖自動切出示範圖
  ├─ assets/thumbs/        ← 每個效果嘅示範縮圖
  └─ app/index.template.html ← 網頁原始碼(模板)
```
